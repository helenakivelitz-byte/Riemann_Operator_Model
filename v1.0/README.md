# Self-Consistent Quantum Operator Model for the Riemann Zeta Function

This repository contains all analytical and numerical materials corresponding to  
the paper:

**Helena Kivelitz (2025).**
*A Self-Consistent Quantum Operator Model for the Riemann Zeta Function.*

## Contents
- `main.tex` — full LaTeX source of the paper
- `Abstract_Kivelitz_ZetaOperator.pdf` — one-page summary
- `proofs/` — Python implementations (Proofs 6–17)
- `figures/` — all figures cited in the paper
- `data/` — numerical data for reproduction
- `results/` — compiled summaries and diagnostics

## Key Results
- Verified λ ≈ 1/(2π) ± 10⁻⁶ after optimal-transport rescaling  
- Uniform convergence of Ψ(s;L) → 1 on compact subsets  
- Bootstrap stability (n = 2000)  
- Newton–Lambert inverse converges within 10⁻¹⁰ in < 7 iterations
